# Use the running key-free application

https://synapse.aaryansomaiah26.workers.dev/

The URL now opens the full SYNAPSE interface with fresh browser-computed simulations. If an older replay page appears, refresh with Ctrl+Shift+R.

Choose a traffic or coffee example, create a world, inspect assumptions and press Play. Pause to branch, then compare both realities at the same simulated minute/day. Change initial assumptions at step zero. Use Steps to select 1–72 time steps and Seed to choose reproducible demand variation.

Knowledge vault extracts PDF/DOCX/TXT/CSV locally. Search for shared keywords; create a new relevant world to include retrieved passages in its Evidence tab. Scanned PDFs require OCR first. Documents do not automatically change model parameters.

My worlds saves in this browser. Export before clearing browser data. There is no cross-device cloud sync or JSON import. Share links embed a read-only snapshot and cannot be revoked.

No API keys are used by this browser edition. External AI research is unavailable. It does not accurately simulate arbitrary disasters or world events.

This GitHub repository is a showcase; uploading it does not redeploy the separately hosted application. Editable browser-edition source is in the private package’s `key-free-web` folder.
