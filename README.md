# ✳ SYNAPSE — Agentic Alternate-Reality Engine

**Change one thing. Explore what happens next.**

## [▶ Open the running application]((https://synapse.aaryansomaiah26.workers.dev/))

No installation, API keys or account required. This is the key-free Sandbox edition with the full v2 interface and fresh browser-computed simulations—not a saved replay.

## Try a world

1. Choose the highway example and click **Create my world**.
2. Inspect **Model & assumptions**, then press Play.
3. Pause at minute 5. Choose **Split reality**, set clearance time to 6, and create the branch.
4. Run both timelines to the same minute and choose **Compare outcomes**.
5. Try the coffee pricing example, or upload a text document in **Knowledge vault** and search for a phrase from it.

## What runs without keys?

- Interactive 3D globe and country selection, with a fallback map.
- Fresh traffic-queue and single-product pricing simulations.
- Play/pause, checkpoint branches, same-time comparisons and numerical ledgers.
- Rule-based stakeholder actions and recent memory.
- PDF/DOCX/TXT/CSV extraction and keyword-based passage retrieval.
- Browser-local saved worlds, JSON export, and read-only snapshot links.

Worlds and extracted documents remain in the visitor’s browser. Clearing site data removes them. Shared snapshot links include scenario text, results and assumptions, but omit document passages and agent memory; anyone with a link can read it and it cannot be revoked.

## Boundaries

Inputs and response coefficients are illustrative assumptions. These models are uncalibrated; they are not validated forecasts or emergency-warning tools. Numerical support is limited to a single traffic bottleneck and single-product pricing. Other scenarios receive a generic evidence checklist and any matching local passages—not invented numerical outcomes or AI-generated analysis.

The browser edition makes no Gemini, Tavily or other external AI calls. It does not execute LangGraph, LangChain, CrewAI or LangSmith. The separate private Python application contains integrations for those tools. The full development source stays in a private repository; browser-delivered code is necessarily inspectable by visitors.

## Verification

Numerical outputs were checked against four Python reference runs. Branch integrity, determinism, unsupported inputs, local storage operations, retrieval and snapshot handling were tested. TypeScript and production builds passed. Browser interaction and PDF/DOCX end-to-end tests were unavailable in this session.
